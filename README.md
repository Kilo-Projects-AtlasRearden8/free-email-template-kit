# Free Email Template Kit

Fillable email templates for everyday work and life: thank-you notes, inquiry
letters, follow-ups, and polite declines. Plain English, warm tone, ready to
copy and send — no account needed, nothing to install.

Published by **Asdale Dynamics, LLC** (Indiana), beginner-friendly tools for
authors, small business owners, healthcare workers, and anyone who just wants to
write a decent email without overthinking it.

## What's inside

| Template | Markdown source | Printable HTML |
|----------|-----------------|----------------|
| Thank-you note | `templates/thank-you-note.md` | `html/thank-you-note.html` |
| Inquiry letter | `templates/inquiry-letter.md` | `html/inquiry-letter.html` |
| Follow-up | `templates/follow-up.md` | `html/follow-up.html` |
| Polite decline | `templates/polite-decline.md` | `html/polite-decline.html` |

Every template uses bracketed placeholders like `[Recipient Name]` and
`[Your Name]`. Fill them in, delete the brackets, and send.

## How to use

**Markdown versions** — open any `.md` file in a text editor, replace the
bracketed fields with your details, then copy the text into your email client.

**Printable HTML versions** — open any `.html` file in your browser, fill in the
fields, then print (Ctrl+P / Cmd+P) or save to PDF. Each page is styled for
clean printing: no screen chrome, no wasted ink.

No sign-up, no tracking, no personal data collected. Everything runs locally in
your browser or editor.
