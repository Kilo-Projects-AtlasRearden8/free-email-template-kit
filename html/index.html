How to use

  • Markdown: Open any .md file in a text editor, replace each [bracketed field] with your details, delete the brackets, then copy into your email.
  • Printable HTML: Open any .html file in your browser, fill in the fields, then print (Ctrl+P / Cmd+P) or save to PDF. Each page is styled for clean printing.
  • No sign-up, no tracking, no personal data collected. Everything runs locally.
